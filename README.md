# Evolución del Comercio Exterior Argentino: Importaciones y Exportaciones 2021-2025

## Descripción del proyecto

Este proyecto analiza la evolución de las importaciones y exportaciones de Argentina durante el período 2021-2025.

El trabajo utiliza datos estadísticos del comercio exterior y analiza diferentes normas relacionadas con las operaciones de comercio exterior y la actividad del despachante de aduana.

## Objetivos

- Analizar la evolución de las exportaciones argentinas entre 2021 y 2025.
- Analizar la evolución de las importaciones durante el mismo período.
- Identificar los cambios en el saldo de la balanza comercial.
- Analizar normas relacionadas con el comercio exterior.
- Relacionar los cambios normativos con la actividad del despachante de aduana.
- Presentar los resultados mediante una página web.

## Herramientas utilizadas

### Perplexity
Se utilizó para realizar la investigación inicial y obtener información sobre las estadísticas de comercio exterior y las normas relacionadas con el tema.

### Excel
Se utilizaron dos archivos de Excel:
- *Excel 1:* datos estadísticos de importaciones y exportaciones de Argentina durante 2021-2025.
- *Excel 2:* información sobre decretos y resoluciones relacionados con el comercio exterior.

### Word
Se utilizó para desarrollar y organizar el análisis escrito del proyecto, incluyendo la introducción, objetivos, metodología, análisis de los datos, normativa y conclusión.

### Cuaderno Gemini
Se utilizó para analizar conjuntamente la información contenida en los archivos Excel y Word.

### Claude
Se utilizó para generar el código HTML de la página web a partir de la información analizada.

### Netlify
Se utilizó para publicar la página web y permitir su visualización.

### GitHub
Se utilizó para almacenar el proyecto, documentar el proceso de trabajo y presentar el resultado final.

## Información analizada

El proyecto comprende:

- Exportaciones de Argentina 2021-2025.
- Importaciones de Argentina 2021-2025.
- Saldo de la balanza comercial.
- Variaciones anuales.
- Decretos y resoluciones relacionados con el comercio exterior.
- Relación de la normativa con la actividad del despachante de aduana.

## Página web

La información analizada se presenta mediante una página web desarrollada en HTML.
